# Segurança

## Versões suportadas

Somente a versão estável mais recente publicada na página de [releases](https://github.com/Wather17/emergence/releases) recebe correções de segurança. A branch `main` pode conter mudanças ainda não publicadas e não é uma versão suportada.

## Reportar uma vulnerabilidade

Não abra uma issue pública para uma vulnerabilidade. Use o formulário privado de [Security Advisories do GitHub](https://github.com/Wather17/emergence/security/advisories/new). Se o formulário não estiver disponível, contate um mantenedor por um canal privado associado à organização do repositório e não envie segredos em canais públicos.

Inclua, quando possível:

- versão do Emergence e sistema operacional;
- passos mínimos para reproduzir o problema;
- impacto esperado e condições necessárias;
- logs sem senhas, chaves, conteúdo de notas ou outros dados privados;
- uma correção sugerida ou um teste de conceito reduzido, sem dados reais.

Não publique senhas, arquivos `sealed.age`, notas abertas, dumps ou detalhes exploráveis antes de uma correção coordenada. O projeto não promete prazo de resposta ou correção; o reporte será avaliado pelos mantenedores.

Para problemas sem impacto de segurança, use as [issues públicas](https://github.com/Wather17/emergence/issues).
